# Internals

The reference material behind the code: long, exhaustive, and written
first for whoever changes the code, coding agents included. To run an
instance, you want [`../deploying.md`](../deploying.md) instead.

- [`design.md`](design.md): the specification. Code cites its sections as `§n`.
- [`decisions.md`](decisions.md): why things are the way they are, with the
  alternatives that were rejected. Cited as `[D-nn]`.
- [`demo.md`](demo.md): building and running the public demo ([D-234]).
- [`impl-notes.md`](impl-notes.md): the test layers and sync suite.

Agents start at [`AGENTS.md`](../../AGENTS.md).
